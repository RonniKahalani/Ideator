# Phases

These are the 5 phases it goes through:

## Discover
  - Research first.
  - Make challenges grounded in the evidence.
  - Each challenge becomes a sticky note in the report.  
## Define
  - Each challenge is rated 1-5 for possible and 1-5 for exciting.
  - The score is the sum.
  - The top 5 challenges are proposed.
  - In ask mode Ideator pauses here for you to take a decision.  
## Develop
  - For each picked challenge, Ideator generates the number of ideas set by the `ideas` [knob](KNOBS.md), fitted to the culture, habits and rules of the chosen `country`[knob](KNOBS.md).  
## Deliver
  - Each idea is rated     - 1-5 for cheap and 1-5 for simple, as a base score.
  - Evidence strength (strong 1.3, some 1.15, none 1.0).
  - Uniqueness (non-obvious 1.2, somewhat 1.1, obvious 1.0) is applied as multipliers. 
  - Weighted score \= (cheap \+ simple) x evidence x uniqueness.
  - The top 5 ideas are picked, with a fixed tie-break: evidence, then uniqueness, then simple, then cheap.
  - Ideas are mixed into concepts.
  - In `ask` mode Ideator pauses again for you to pick concepts.  
## Preto
  - Tests are written for the picked concepts, with one recommended first test per concept.
  - Creates ready-to-use materials for each test.
