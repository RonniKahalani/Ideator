# Marketplace
The Ideator bot is currently not shared, published or available on any marketplace.

## Memories
- Only mode (auto or ask). Knobs aren’t saved; they apply to one run.  

## Skills
- The Double Diamond playbook. It runs Discover, Define, Develop and Deliver, then a pretotype test plan and a visual board.

## Routines
- None for now. Only runs when you give it a problem statement (+ any optional knobs/parameters).

## Integrations
- Web research for sources, and saving each stage and the final report file (markdown or page) and board image. It doesn't delete anything.
